## explanation
ห้าข้อนี้ไม่มีตัวอย่างให้คัดลอก แต่ละข้อต้องใช้ของจากคนละกลุ่มบท เช่น struct กับ error, JSON กับ error ที่ห่อไว้, งานคู่ขนานที่หยุดตาม context, HTTP ที่ต่อที่อยู่แล้วเขียน log, และการเรียก interface ที่อาจ panic

ตัวอย่างในบทก่อนหน้าแก้โจทย์ข้อนั้นข้อเดียว การส่งโค้ดจากบทเดียวมาจึงไม่ผ่านเทสต์ที่ซ่อนไว้

## apply
ใช้ตอนงานจริงที่ฟังก์ชันเดียวต้องตรวจ input, จำกัดงานคู่ขนาน, และรายงานความพลาดโดยไม่ให้ทั้งก้อนล่ม

## easy
จัดข้อมูลใน slice ให้เข้าช่วง และปฏิเสธชื่อที่ว่างโดยไม่ panic เมื่อได้ nil

## hard
เรียกพฤติกรรมที่อาจ panic ทีละตัว แล้วไปต่อตัวที่เหลือ

## steps
- อ่านสัญญาของฟังก์ชัน
- แยกเคสสำเร็จ เคส error และเคส panic
- อย่า hardcode ค่าจากตัวอย่างในหัว
- ให้ผ่านทุกชุดที่เทสต์ซ่อนไว้
