## explanation
memory model บอกว่าการเขียนค่าหนึ่งจะถูกการอ่านอีก goroutine เห็นเมื่อไร การส่งผ่าน channel มี happens-before ระหว่างการส่งที่สำเร็จกับการรับที่คู่กัน แค่เห็นลำดับครั้งเดียวไม่ได้พิสูจน์ว่าไม่มี data race

```
ch <- 1
v := <-ch
```

## apply
ใช้เมื่อต้องอธิบายพฤติกรรมที่การรันครั้งเดียวพิสูจน์ไม่ได้

## easy
เคสง่ายคือตัวเลือกที่ตรงนิยาม

## hard
เคสยากคือตัวเลือกที่คนมักสับสนกับของใกล้เคียง

## steps
- อ่านคำถาม
- ตัดตัวเลือกที่ขัดกติกา
- เลือกข้อที่ตรงพฤติกรรม
- ส่งคำตอบในหน้านี้
