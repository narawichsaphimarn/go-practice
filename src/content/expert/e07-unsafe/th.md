## explanation
unsafe.Pointer ข้ามระบบชนิดของภาษา การแปลงผิดทำให้ได้ pointer ที่ไม่ชี้ออบเจ็กต์ที่มีชีวิต แบบฝึกนี้เป็นควิซอย่างเดียว เพื่อไม่ส่งโค้ด unsafe ไปรันบน runner

```
// อธิบายผลที่พัง อย่าส่งแพ็กเกจ unsafe ไปรัน
```

## apply
ใช้เมื่อต้องอธิบายพฤติกรรมที่การรันครั้งเดียวพิสูจน์ไม่ได้

## easy
เคสง่ายคือตัวเลือกที่ตรงนิยาม

## hard
เคสยากคือตัวเลือกที่คนมักสับสนกับของใกล้เคียง

## steps
- อ่านคำถาม
- ตัดตัวเลือกที่ขัดกติกา
- เลือกข้อที่ตรงพฤติกรรม
- ส่งคำตอบในหน้านี้
