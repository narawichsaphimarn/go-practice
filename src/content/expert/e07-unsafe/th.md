## explanation
แพ็กเกจ unsafe ข้ามระบบชนิดของ Go ข้อนี้ไม่ส่งโค้ด unsafe ไปรัน เพราะตัวตรวจไม่รับโค้ดที่ข้ามชนิดแบบนั้น

```
b := []byte("go")
fmt.Println(b)
```

นี่คือทางดูไบต์ของสตริงโดยไม่ใช้ unsafe

## apply
การแปลง pointer ผิดได้ pointer ที่ไม่ชี้ออบเจ็กต์ที่มีชีวิต แล้วอ่านค่ามั่วหรือ panic ทางที่ปลอดภัยกว่าเมื่ออยากได้ไบต์ของสตริงคือแปลงเป็น []byte ซึ่งก็อปข้อมูล

```
func bytesOf(s string) []byte {
	return []byte(s)
}
```

bytesOf("go") ได้สไลซ์ไบต์ของ g และ o โดยไม่ถือ pointer เข้าไปในสตริงเดิม

## easy
ตัวตรวจไม่รับโค้ดที่ข้ามชนิดด้วย unsafe ใช้การแปลงธรรมดาแทน

```
b := []byte("go")
```

## hard
ทางที่ปลอดภัยกว่า unsafe เมื่ออยากได้ไบต์ของสตริงคือ []byte(s) การแปลง pointer ผิดได้ pointer ที่ไม่ชี้ออบเจ็กต์ที่มีชีวิต

```
func bytesOf(s string) []byte {
	return []byte(s)
}
```
