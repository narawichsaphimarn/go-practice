## explanation
เวลาส่งตัวแปรเข้าฟังก์ชัน Go ส่งสำเนาไปให้ เหมือนส่งไฟล์ก๊อปปี้ทางแชต คนรับแก้ไฟล์ของเขาเท่าไร ไฟล์ของเราก็ไม่เปลี่ยน

```
func reset(n int) {
	n = 0
}

x := 5
reset(x)
fmt.Println(x)
```

ได้ 5 เพราะ reset แก้แค่สำเนา

pointer คือที่อยู่ของตัวแปร เหมือนส่งลิงก์ไฟล์แทนตัวไฟล์ คนรับเปิดลิงก์แล้วแก้ ไฟล์ตัวจริงก็เปลี่ยน เครื่องหมายที่ใช้มีสองตัว:

- `&x` คือที่อยู่ของ x
- `*int` คือชนิด "pointer ที่ชี้ไปยัง int"
- `*p` คือค่าที่ p ชี้อยู่ ใช้ได้ทั้งอ่านและเขียน

เครื่องหมาย `*` จึงมีสามความหมายตามตำแหน่ง: หน้าชื่อชนิด (`*int`) คือชนิด pointer, หน้าตัวแปร (`*p`) คือค่าที่ชี้อยู่ และระหว่างตัวเลขสองตัว (`a * b`) คือการคูณ

## apply
แก้ตัวอย่างข้างบนให้แก้ค่าตัวจริงได้

```
func reset(n *int) {
	*n = 0
}

x := 5
reset(&x)
fmt.Println(x)
```

ได้ 0 เพราะส่งที่อยู่ของ x ไป แล้ว `*n = 0` เขียนลงที่อยู่นั้น

pointer ที่ยังไม่ได้ชี้อะไรเลยมีค่าเป็น `nil` ถ้าอ่าน `*p` ตอนที่ p เป็น nil โปรแกรมจะ panic จึงควรเช็ก `if p == nil` ก่อนเมื่อไม่แน่ใจ

## easy
ตัวอย่าง: ตั้งค่าตัวแปรเป็นสองเท่าผ่าน pointer

```
func DoubleIt(n *int) {
	*n = *n * 2
}

x := 4
DoubleIt(&x)
```

หลังเรียก x เป็น 8 ในบรรทัด `*n = *n * 2` ดาวสองตัวแรกคือค่าที่ชี้อยู่ ส่วนดาวตัวสุดท้ายคือการคูณ

## hard
ตัวอย่าง: ตั้งค่าเป็น 0 เฉพาะตอนที่ pointer ชี้อะไรอยู่จริง แล้วบอกว่าทำได้ไหม

```
func Clear(n *int) bool {
	if n == nil {
		return false
	}
	*n = 0
	return true
}
```

`Clear(nil)` ได้ false โดยไม่ panic ส่วน `Clear(&x)` ตั้ง x เป็น 0 แล้วคืน true
