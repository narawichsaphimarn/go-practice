## explanation
ไฟล์ในโฟลเดอร์เดียวกันที่เป็น package เดียวกันประกอบกันเป็นหนึ่ง package go.mod บอกขอบเขตของโมดูล แบบฝึกนี้ยังอยู่ใน package main ไฟล์เดียว เพราะ runner รับซอร์สเดียว แต่หลักคือแยกฟังก์ชันให้ชื่อขึ้นต้นด้วยตัวใหญ่เมื่อจะให้คนนอก package เรียก

```
func Greet(name string) string {
	return "hello " + name
}
```

## apply
ใช้ตอนแยก helper ออกจาก main เพื่อให้ package อื่นในโมดูลเดียวกันเรียกได้

## easy
ทักทายด้วยชื่อ

## hard
ต่อสตริง หรือคืนรุ่นภาษา

## steps
- ตั้งชื่อที่ขึ้นต้นด้วยตัวใหญ่
- เก็บไว้ใน package main ไฟล์นี้
- อย่าพึ่งพาโมดูลภายนอก
- ให้เทสต์เรียกชื่อนั้น
