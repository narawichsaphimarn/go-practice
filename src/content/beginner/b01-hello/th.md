## explanation
โปรแกรม Go ที่เล็กที่สุดที่พิมพ์ข้อความได้มีห้าบรรทัด

```
package main

import "fmt"

func main() {
	fmt.Println("hello")
}
```

อ่านทีละบรรทัดได้แบบนี้:

- `package main` บอกว่าไฟล์นี้เป็นโปรแกรมที่รันได้ (แพ็กเกจคือกลุ่มของโค้ด บทที่ 9 จะเล่าเพิ่ม)
- `import "fmt"` ขอใช้แพ็กเกจ `fmt` ซึ่งมีคำสั่งพิมพ์ข้อความ
- `func main() { ... }` คือจุดเริ่มของโปรแกรม Go จะทำคำสั่งในวงเล็บปีกกาจากบนลงล่าง
- `fmt.Println("hello")` พิมพ์คำว่า hello แล้วขึ้นบรรทัดใหม่

ข้อความที่อยู่ในเครื่องหมายคำพูด เช่น `"hello"` เรียกว่าสตริง (string) ตัวเลขไม่ต้องใส่เครื่องหมายคำพูด เช่น `fmt.Println(1 + 2)` จะพิมพ์ 3 เพราะ Go คำนวณให้ก่อน

## apply
คำสั่งพิมพ์ที่ใช้บ่อยมีสามตัว:

- `fmt.Println(...)` พิมพ์แล้วขึ้นบรรทัดใหม่ ถ้าส่งหลายค่าจะคั่นด้วยช่องว่าง เช่น `fmt.Println("total:", 2+5)` ได้ `total: 7`
- `fmt.Print(...)` พิมพ์โดยไม่ขึ้นบรรทัดใหม่ ครั้งต่อไปจึงพิมพ์ต่อท้ายบรรทัดเดิม
- `fmt.Printf("...", ...)` พิมพ์ตามแบบที่กำหนด `%d` คือช่องสำหรับตัวเลข ส่วน `\n` คือขึ้นบรรทัดใหม่ ซึ่ง Printf ไม่ใส่ให้เอง

เครื่องหมาย `+` ระหว่างสตริงสองชิ้นคือการต่อข้อความ เช่น `"Go" + "pher"` ได้ `Gopher`

## easy
ตัวอย่าง: พิมพ์ชื่อผลไม้สองบรรทัด

```
package main

import "fmt"

func main() {
	fmt.Println("apple")
	fmt.Println("banana")
}
```

ผลคือ

```
apple
banana
```

## hard
ตัวอย่าง: พิมพ์ราคารวมของสินค้า 2 ชิ้น ชิ้นละ 15 บาท โดยให้ Go คูณเอง

```
package main

import "fmt"

func main() {
	fmt.Printf("total=%d baht\n", 2*15)
}
```

ผลคือ `total=30 baht` เพราะ Printf เอาผลของ `2*15` ไปใส่แทน `%d`
