## explanation
โปรแกรม Go เริ่มที่ package main และฟังก์ชัน main

```
package main

func main() {}
```

คำสั่ง go run คอมไพล์แล้วรันแพ็กเกจในโฟลเดอร์นั้น โมดูลขั้นต่ำมีไฟล์ go.mod ที่บอกชื่อโมดูลกับรุ่นภาษา Go 1.25

## apply
ใช้เป็นจุดเริ่มของเครื่องมือบรรทัดคำสั่งและของ service ที่รันค้าง

## easy
พิมพ์คำเดียวหนึ่งบรรทัด

## hard
พิมพ์สองบรรทัดหรือประกอบข้อความจากค่าที่คำนวณ

## steps
- เปิดไฟล์ main.go
- ตรวจ package main
- รันโปรแกรม
- อ่าน stdout
