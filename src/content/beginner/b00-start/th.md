## explanation
เว็บนี้ให้เขียนภาษา Go แล้วตรวจคำตอบได้ทันที ไม่ต้องติดตั้งอะไรในเครื่อง แต่ละบทมีคำอธิบายสั้น ๆ แล้วตามด้วยโจทย์สี่ข้อ ได้แก่ ง่าย กลาง ยาก และข้อพิเศษ

โจทย์มีสามแบบ:

- พิมพ์ผล (stdout): โปรแกรมมี `func main` เว็บจะรันโปรแกรมแล้วเทียบสิ่งที่พิมพ์ออกมากับคำตอบทีละตัวอักษร
- ทดสอบ (test): โจทย์ให้เขียนฟังก์ชันอย่างเดียว ไม่มี `func main` โค้ดทดสอบที่ซ่อนอยู่ในเว็บจะเรียกฟังก์ชันนั้นด้วยค่าหลายชุด แล้วเทียบผลกับคำตอบที่ถูก
- ปรนัย (quiz): เลือกคำตอบในหน้าบทเรียน แล้วกดส่ง

## apply
หน้าโจทย์มีช่องเขียนโค้ดและปุ่มสี่ปุ่ม:

- `จัดรูปแบบ` จัดย่อหน้าและช่องว่างของโค้ดให้เป็นแบบมาตรฐานของ Go
- `ตรวจ vet` หาโค้ดที่น่าจะผิดก่อนรัน
- `รัน` รันโปรแกรมที่มี `func main` แล้วแสดงผลลัพธ์ ใช้ดูผลเฉย ๆ ยังไม่ตรวจคำตอบ
- `ส่งคำตอบ` ตรวจตามกติกาของโจทย์ ถ้าผ่านจะบันทึกคะแนนให้

โจทย์แบบทดสอบไม่มี `func main` จึงกดรันไม่ได้ ให้กดส่งคำตอบเลย ถ้าไม่ผ่าน ช่องผลลัพธ์จะบอกว่าค่าไหนผิด

## easy
ตัวอย่าง: โจทย์บอกว่า "พิมพ์คำว่า hi" และโค้ดเริ่มต้นเป็นแบบนี้

```
package main

import "fmt"

func main() {
	fmt.Println("todo")
}
```

แก้เฉพาะคำว่า `todo` ในเครื่องหมายคำพูดให้เป็น `hi` แล้วกดส่งคำตอบ ส่วนอื่นยังไม่ต้องเข้าใจ บทถัดไปจะอธิบายทีละบรรทัด

## hard
ตัวอย่าง: โจทย์แบบทดสอบบอกว่า "แก้ Triple ให้คืนสามเท่าของ n" โค้ดเริ่มต้นคือ

```
func Triple(n int) int {
	return n
}
```

`return` คือส่งค่ากลับไปให้คนที่เรียก ตอนนี้ฟังก์ชันส่ง `n` กลับไปตรง ๆ จึงต้องแก้เป็น `return n * 3` (`*` คือคูณ) แล้วกดส่งคำตอบ โค้ดทดสอบจะลองเรียก `Triple(2)` แล้วดูว่าได้ 6 จริงไหม
