## explanation
การส่ง struct หรือ int เข้าฟังก์ชันคือการก็อป pointer ชี้ไปที่ค่าเดิม การแก้ผ่าน *n จึงเห็นนอกฟังก์ชัน

```
func Inc(n *int) {
	*n++
}
```

## apply
ใช้เมื่อต้องแก้ค่าของผู้เรียก เช่น เพิ่มตัวนับ สลับสองค่า หรือตั้งชื่อใน struct

## easy
เพิ่มค่าผ่าน pointer

## hard
สลับสองค่า หรือตั้งฟิลด์ผ่าน pointer

## steps
- ใส่ * ที่ชนิดพารามิเตอร์
- ใช้ & ตอนส่งที่อยู่
- อย่าลืมตรวจ nil ถ้าผู้เรียกส่งได้
- แก้ค่าแล้วคืนให้ผู้เรียกเห็น
