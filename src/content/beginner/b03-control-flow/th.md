## explanation
โปรแกรมไม่ได้ทำทุกบรรทัดเสมอไป บางทีต้องเลือกทาง และบางทีต้องทำซ้ำ เครื่องมือหลักมีสามตัว: `if` เลือกทำเมื่อเงื่อนไขเป็นจริง, `for` ทำซ้ำ และ `switch` เลือกตามค่า

เงื่อนไขสร้างจากการเทียบค่า:

- `==` เท่ากัน, `!=` ไม่เท่ากัน
- `<` น้อยกว่า, `<=` น้อยกว่าหรือเท่ากัน, `>` มากกว่า, `>=` มากกว่าหรือเท่ากัน
- `&&` และ, `||` หรือ, `!` ไม่ (กลับค่าความจริง)

```
age := 20
if age >= 18 {
	fmt.Println("adult")
} else {
	fmt.Println("child")
}
```

ได้ `adult` เพราะ 20 มากกว่าหรือเท่ากับ 18 ส่วน `else` คือทางที่ทำเมื่อเงื่อนไขเป็นเท็จ

## apply
`for` แบบนับรอบมีสามส่วนคั่นด้วย `;`

```
for i := 1; i <= 3; i++ {
	fmt.Println(i)
}
```

- `i := 1` ทำครั้งเดียวก่อนเริ่ม
- `i <= 3` เช็กก่อนทุกรอบ ถ้าเป็นเท็จก็หยุด
- `i++` ทำหลังจบแต่ละรอบ หมายถึงเพิ่ม i ขึ้นหนึ่ง (ส่วน `i--` คือลดลงหนึ่ง)

ผลคือ 1, 2, 3 คนละบรรทัด

`switch` เทียบค่าหนึ่งตัวกับหลายกรณี แล้วทำเฉพาะกรณีที่ตรง ไม่ต้องเขียน break

```
light := "red"
switch light {
case "red":
	fmt.Println("stop")
case "green":
	fmt.Println("go")
default:
	fmt.Println("wait")
}
```

`default` คือกรณีที่ไม่ตรงกับ case ไหนเลย

## easy
ตัวอย่าง: พิมพ์คำว่า even เมื่อเลขเป็นเลขคู่ (`%` คือเศษจากการหาร)

```
n := 6
if n%2 == 0 {
	fmt.Println("even")
}
```

## hard
ตัวอย่าง: พิมพ์เลขคี่ตั้งแต่ 1 ถึง 7 บรรทัดละตัว

```
for i := 1; i <= 7; i += 2 {
	fmt.Println(i)
}
```

`i += 2` คือ `i = i + 2` ลูปจึงได้ 1, 3, 5, 7 แล้วหยุด เพราะรอบถัดไป i เป็น 9 ซึ่งไม่ผ่านเงื่อนไข `i <= 7`
