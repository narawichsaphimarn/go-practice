## explanation
if ไม่มีวงเล็บรอบเงื่อนไข for เป็นได้ทั้งลูปและ while switch เทียบค่าแล้วจบเคสเองโดยไม่ fall through

```
if score >= 80 {
	fmt.Println("pass")
}
```

## apply
ใช้ตัดสินใจใน handler, กรองรายการ, และแปลงรหัสสถานะเป็นข้อความ

## easy
เงื่อนไขเดียวที่พิมพ์ pass

## hard
ลูปประกอบข้อความ หรือ switch ที่เลือกชื่อวัน

## steps
- เลือก if, for หรือ switch
- ใส่ค่าที่โจทย์กำหนด
- พิมพ์ผล
- อย่าพิมพ์ข้อความส่วนเกิน
