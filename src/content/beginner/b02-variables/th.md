## explanation
ตัวแปรคือกล่องที่มีชื่อแปะไว้ ใส่ค่าไว้ในกล่องแล้วเรียกใช้ด้วยชื่อทีหลังได้ ทุกกล่องมีชนิด (type) บอกว่าใส่ค่าแบบไหนได้:

- `int` ตัวเลขจำนวนเต็ม เช่น 0, 42, -7
- `string` ข้อความ เช่น "go"
- `bool` ค่าความจริง มีแค่ `true` (จริง) กับ `false` (เท็จ)

ประกาศตัวแปรได้สองแบบ:

```
var count int
lang := "go"
```

บรรทัดแรกใช้ `var` บอกชื่อกับชนิด แต่ยังไม่ใส่ค่า บรรทัดที่สองใช้ `:=` ประกาศพร้อมใส่ค่า แล้วให้ Go ดูชนิดจากค่าเอง (`lang` จึงเป็น string) ส่วน `:=` ใช้ได้เฉพาะในฟังก์ชัน

ตัวแปรที่ประกาศแต่ยังไม่ใส่ค่าจะได้ค่าศูนย์ (zero value) ของชนิดนั้น: int ได้ `0`, string ได้ข้อความว่าง `""`, bool ได้ `false`

## apply
ใช้ `=` เปลี่ยนค่าในกล่องที่มีอยู่แล้ว และใช้ `:=` เฉพาะตอนสร้างกล่องใหม่

```
score := 10
score = score + 5
fmt.Println(score)
```

ผลคือ 15 บรรทัดที่สองอ่านว่า "เอาค่าเดิมของ score บวก 5 แล้วใส่กลับเข้ากล่อง score"

ข้อควรรู้: Go ไม่ยอมคอมไพล์ถ้าประกาศตัวแปรแล้วไม่ได้ใช้ ข้อความ error จะบอกว่า `declared and not used` ถ้าเจอแบบนี้ให้ใช้ตัวแปรนั้นหรือลบทิ้ง

## easy
ตัวอย่าง: เก็บชื่อเมืองไว้ในตัวแปร แล้วพิมพ์

```
city := "Bangkok"
fmt.Println(city)
```

ได้ `Bangkok` เพราะพิมพ์ค่าที่อยู่ในกล่อง city ไม่ได้พิมพ์คำว่า city ถ้าเขียน `fmt.Println("city")` ที่มีเครื่องหมายคำพูด จะได้คำว่า city แทน

## hard
ตัวอย่าง: ดูค่าศูนย์ของ string แล้วเปลี่ยนค่า

```
var name string
fmt.Println(name == "")
name = "Ann"
fmt.Println(name)
```

ผลคือ `true` แล้ว `Ann` บรรทัดแรกพิมพ์ true เพราะ name ยังเป็นข้อความว่างอยู่ (`==` คือการเทียบว่าเท่ากันไหม)
