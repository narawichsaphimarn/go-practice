## explanation
table test เก็บ input กับผลที่ต้องการไว้ใน slice แล้ววนเรียกฟังก์ชันเดียว เคสพังควรอยู่แถวเดียวกับเคสปกติ เพื่อไม่ให้ลืม

```
cases := []struct {
	n    int
	want string
}{
	{-1, "neg"},
	{0, "zero"},
	{2, "pos"},
}
```

## apply
ใช้กับฟังก์ชันบริสุทธิ์ที่แปลงค่า เช่น จัดประเภทตัวเลขหรือตรวจช่วง

## easy
จัดประเภทจำนวน

## hard
ตรวจว่าค่าอยู่ในช่วง หรือคืนเครื่องหมาย

## steps
- แยกเคสปกติกับเคสขอบ
- ใช้ชื่อเคสในข้อความ error
- อย่าแชร์ตัวแปรระหว่างแถว
- รันทุกแถวแม้แถวก่อนหน้าพังด้วย t.Run
